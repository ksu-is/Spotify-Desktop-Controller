# Spotify-Desktop-Controller
This project is a Python-based desktop application that allows users to control Spotify playback across compatible devices.

## Planned Features
- Play, pause, and skip songs
- Volume controller
- Display song/artist information and album artwork
- Customizable retro radio inspired interface
- Minimized player mode

## Technologies
- Python
- Spotipy
- Spotify Web API
- GUI library (to be determined)
